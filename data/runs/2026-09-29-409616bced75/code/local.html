자료를 읽고 비교하기

종목 탐색에서 기업을 고르고, 현금과 가격의 가정을 조절합니다. 사업부·비교 기업·원문·판단 이력은 같은 기업 화면에 연결돼 있습니다.

가정을 움직인 결과는 탐색용입니다. 저장된 원장이나 당시 의견이 자동 변경되지는 않습니다.

02 / REPLAY

저장 자료로 재계산

공시·가격 사본을 다시 계산하고 화면·PDF를 검사합니다. 외부 연결과 모델 추론을 요청하지 않습니다. 프로젝트 폴더의 터미널에서 실행하세요.

python3 start.py offline
03 / REASON

로컬 모델로 다시 읽기

설치된 로컬 모델로 가설·반론·검토를 생성하고 평가합니다. GPU가 다른 작업에 사용 중이면 해당 작업을 변경하지 않고 대기하거나 보류합니다.

python3 start.py research

모델 파일은 프로젝트 .local/models에 둡니다. 생성과 자체 점검은 독립 금융 해석 승인을 뜻하지 않습니다.

새 공시를 가져올 때

인터넷 수집은 별도 동작입니다. 공개 공시·가격을 갱신한 뒤 상세 원문과 로컬 판독을 다시 연결합니다. 한국 공시는 DART 키가 필요하며, 키를 보고서에 붙여 넣지 않습니다.

python3 start.py collect --dart-env /권한있는/키파일

DART_API_KEY를 이미 환경에 설정했다면 --dart-env를 생략합니다. 수집 실패·미확인 원문은 결과에 남습니다.

실패했을 때 복구하는 순서
  1. python3 start.py status현재 분석과 마지막 검증 버전, 실패한 단계의 로그를 확인합니다.
  2. 원문 실패라면 인터넷·키를 확인한 뒤 수집을 재실행합니다. 기존 성공본과 실패 기록은 유지합니다.
  3. 모델 실패라면 python3 scripts/local-coverage.py --resume --wait-gpu-seconds 3600동일 입력·모델·설정의 완료 기록을 재사용하고 미완료 기업을 처리합니다.
  4. 화면이나 PDF 실패라면 원인을 수정하고 python3 start.py offline같은 자료로 검사와 출력을 다시 수행합니다. 모델 수정 필요 상태와 출력 실패는 별도로 표시합니다.

해석할 때 확인할 범위

계산과 출처공시 기간·단위·연결 범위와 보존 원문의 해시를 확인합니다.
가격 시나리오현금창출·재투자·배분 부담·성장·요구수익률의 조건부 계산입니다. 미확인 증권 범위는 주당 가격 계산을 보류합니다.
로컬 AI초안·비판·수정·실패를 보존합니다. 문장 평가와 실제 투자 성과는 구분합니다.
미래 관측등록 이후 새 공시·가격을 기다립니다. 아직 오지 않은 결과를 소급해 채우지 않습니다.

분석과 기록은 이 폴더에 남습니다. 기존 공개 사이트는 별도이며 새 내부 결과가 자동 발행되지 않습니다.
